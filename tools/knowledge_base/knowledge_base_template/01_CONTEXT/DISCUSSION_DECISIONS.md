# 讨论结论与决策沿革

这是按主题整理的交接索引，不替代 `02_CONVERSATIONS` 对话原文。历史讨论可能彼此冲突，
下面明确区分现行要求、已实现机制、负结果和待验证提案。

## 已明确的项目约定

- 所有验证只用无延迟固件，不再启用旧延迟仓库。执行器本身的关节 PID、电机动态不等于人为纯延迟。
- 分配方法之间共享外环参数、任务、物理模型和最终执行器约束；以运行时快照核验，不能仅比较输入 JSON 哈希。
- 保留失败样本、真实高度、SO(3)、角速度、arming/截止、估计误差与执行器反馈。轨迹时钟结束不等于飞行成功。
- 仿真可自动执行任务；实机不自动 Arm、切模式或起飞，人工开关触发控制。
- 舵机 500–2500 与电机映射分开。二级减速比、物理关节角和轴角分开，尾电机正反推力、偏置及 CG 补偿分开。
- Git 归并至同仓库文件夹组织；保留未提交工作，不 reset、自动切分支或覆盖历史。最新本地改动不等于远端 main 已同步。

## 算法为何演进到现在

1. 从解析直接分配与基本微分分配出发，引入执行器可达状态、变化率、短预测时域和有限计算量求解。
2. 后续发现左右/偏航振荡，不能仅靠降低外环增益解释；重点检查模型、几何、执行器可达速率、时序和反馈。
3. 可达扳手/变化率契约接入诊断与反算抗饱和，但不能把它说成已经改变轨迹的完整 reference governor。
4. 用户提出以实测 Joint PID 闭环动态辨识建立 Phi_H/S_H，并用未来轨迹扳手替代“未来状态追当前扳手”。
5. 实现两点未来目标、实测角覆盖、GN 与 move blocking 后，再加入近期平衡软项，修复大姿态任务接管/启停。
6. NDA 核对发现连续动态逆的采样失配、固定悬停偏好和双轴自运动问题，按论文结构修正采样适配。
7. 磁场 ENU/NED/FRD 约定、关节模型稳态增益和空中误判着陆也影响结果，不能将这些修复收益全部归于新分配理论。

## 被数据限制或推翻的说法

- “调参后比原来更好”曾被用户根据对比图质疑；必须看相同评估窗口、有效状态与失败段，不能选择性指标。
- Full 并非普遍更好：最新 7 s 李萨如有局部优势；5 s 单步更好；大姿态无未来参考更好。
- 早期 Basic DA 失稳不能算作完整论文方法失败；后来修复的 NDA 也只是 Hnuter 采样/力坐标适配。
- 执行器命令、PWM 或 esc_rpm 命令回声不是物理关节角、转速或真实扳手测量。
- 心跳正常/单测通过不能证明实机接管稳定；最近仍有明显异常且新 ULog 未取回。

## 实机接管策略的最新变更

过去依赖旧姿态目标、参数读回、参考范围/误差及模型扳手一致性的接管拒绝，
使用户手动切 Offboard 后退出。后来按明确请求取消这些附加接管门槛：
**连续心跳、人工 Armed+Offboard、切换实测位姿、0.5 s 过渡**。
它并未取消运行中对坏数据、估计器重置、超物理范围和数值错误的检查。
最近退出原因是估计器倾角 30.1°触发运行保护，而非旧门槛残留；因缺日志不能继续归因。
