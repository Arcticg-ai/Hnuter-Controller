## 解压后先验证

```bash
python3 08_TOOLS/verify_bundle.py
python3 08_TOOLS/search.py "接管"
python3 08_TOOLS/search.py "未来参考"
```

也可 `sha256sum -c SHA256SUMS`。压缩包外的同名 `.sha256` 用于核验整个压缩包。

原始源码按快照保存；运行前在另一个目录创建路径适配副本，参见迁移文档。
历史报告和对话中的绝对路径、旧 PID、旧 IP、旧参数及“当前运行”不能直接当成今日状态。
现行政策：**永远不再以延迟固件验证；只用无延迟固件；分配实验直接发送电机/舵机 DDS 消息。**

## 完整性与隐私边界

本包包含现存报告里的失败样本、原始 ULog 和完整参数，属于私人调试资料，勿未经检查公开发布。
对话只导出可见文字，已脱敏密码/网页令牌；不包含内部推理、工具原始输出、SSH 密钥、账号配置。
未同步最新未取回的机载日志，不伪造缺失证据。来源与遗漏见 `09_PROVENANCE/`、`02_CONVERSATIONS/index.json`。
历史嵌套源码压缩包会展开为 `.expanded/`，并记录原包哈希，便于检索与凭据检查。

没有连接远程主机，没有改变源仓库、推送 Git、启动 Gazebo 或启动实际控制输出。
