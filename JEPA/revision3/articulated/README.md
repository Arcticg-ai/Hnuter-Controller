已实现：

- `spatial_model.py`：固定base_link原点的角动量积分。运动部件的 Δh(q)、ΔJO(q)、hrel,O 由独立标称装配校准计算，未知刚性负载在O点的增量保持常值。质量与hz固定，候选参数为 hx、hy 和对称JO的六个分量，共8个；Jc由平行轴定理恢复并检查物理性。扩展原因是固定原点的积惯量随未知CoM平移，不能把它们仍当已知常数。
- `test_spatial.py`：3项测试通过。验证完整张量往返、两载荷在任意倾转/转子状态下具有相同标称运动修正、8参数合成积分回收。此模块是回归/物理检查原语，尚不是完成验收门控的在线估计器。
- `diagnose_timing.py`：两个预选旧日志，滤波角速度/原始IMU、±24 ms时移诊断；前半窗选时移，后半窗验证。测试使用真值参数仅评分，未写入在线配置。不同日志选出的最佳方案不同，不能视为独立校准好了固定延迟。
