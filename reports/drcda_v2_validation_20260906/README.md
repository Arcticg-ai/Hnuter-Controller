## 方法口径

1. `Original direct`：原解析几何分配。
2. `Paper NDA`：复现 Cuniato 等论文 Eq. 7-13，包括 `k_j(w_d-w(q))`、动态速率上下界归一化、无执行器权重伪逆、零空间目标和整向量统一饱和。
3. `DRCDA v1`：优化前标签中的现有可达域微分分配。
4. `DRCDA v2`：独立实验入口和配置。失败的单调线搜索及解析候选保护均已撤销，活动版本沿用已验证的 v1 求解路径，不能宣称已获得统计优势。

当前无延迟 Gazebo 模型没有独立一阶执行器插件，也没有真实执行器状态反馈，所以 `Paper NDA` 未执行论文 Eq. 14 的一阶动力学逆，亦不包含 Eq. 15-19 的 PDA 功率曲线。其结果只能评价 NDA 核心在当前 Hnuter 模型上的直接适配，不能代表论文完整硬件方案。

## 被拒绝的优化

- 初始单调 LM/回溯求解器：高速轨迹翻转失稳，位置 RMSE `5.71 m`。
- 修正命令投影后：恢复飞行但位置 RMSE `1.35 m`，仍不合格。
- 数值尺度回归后：位置 RMSE `0.789 m`，不如 v1。
- 横滚力矩增权：舵机活动率下降，但位置和姿态同时变差。
- 解析候选保护：内部预测代价更低时切换，真实闭环却恶化到 `0.899 m / 18.9 deg`，证明该内部代价不能单独作为在线选择准则。

## 结论

当前推荐继续使用 `DRCDA v1`。本次完成了仓库无丢失迁移、远程硬件代码同步、论文 NDA 口径修正、独立实验副本和可复现实验编排，但没有证据支持将 v2 替换为主算法。

下一步应先增加 Gazebo 执行器状态反馈，并按论文 Eq. 14 实现与被控对象一致的一阶动力学逆；随后用固定随机种子和至少三次重复实验优化。没有这两项，单次仿真的小幅排名变化不可靠。
